<h1 align="center">Backend</h1>

The `backend` directory represents the main server-side application area of the DevSecOps demonstration. This part of the repository is assigned to Zakhar Bolshakov and Nikita Khripunkov and is intended for a Go/Golang backend service that can be containerized, analyzed, and evaluated by the secure CI/CD pipeline design.
